⚙️ Setup

Eenmalige configuratie. De sleutels worden opgeslagen in je browser (localStorage). Doe dit op elke telefoon die je gebruikt (Bert & Ellen apart).

1ImgBB API Key — voor foto's

Maak een gratis account op imgbb.com
Ga naar api.imgbb.com → kopieer je API key

2GitHub Gist — voor dagboekdata

Token: ga naar github.com/settings/tokens
→ "Generate new token (classic)" → vink alleen "gist" aan → kopieer

Gist ID: ga naar gist.github.com
→ Maak nieuwe private Gist aan → bestand noem je colombia_reis.json → inhoud: {}
→ De Gist ID is de lange hash in de URL: gist.github.com/jouwNaam/abc123...

3Wie ben jij?

Kies op welke telefoon je dit instelt. Dagboekentries worden opgeslagen met jouw naam.
